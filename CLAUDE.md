# Claude Code entry point

For a first-time user, read `AGENTS.md` and `ONBOARDING.md`, then guide them through the native Gmail and Google Calendar connector authorization flow. For a returning user, execute the daily workflow in `AUTOMATION_PROMPT.md`.

For Google services, use the user's configured Gmail and Google Calendar integrations. Ask the user to connect them if unavailable. Never ask for or store a Gmail password.
